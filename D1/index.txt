PART 1 — Share Folder Between Host OS and Cloudera VM

This is the BEST method for transferring files easily.

If You Are Using VirtualBox
Step 1 — Install Guest Additions

Start Cloudera VM.

From VirtualBox menu:

Devices → Insert Guest Additions CD Image

Open terminal in VM:

sudo yum update
sudo yum install gcc kernel-devel kernel-headers dkms make bzip2 perl -y

Mount CD:

sudo mount /dev/cdrom /mnt

Install:

sudo /mnt/VBoxLinuxAdditions.run

Reboot:

sudo reboot
Step 2 — Create Shared Folder

In VirtualBox:

Settings → Shared Folders

Add folder:

Folder Path → Select your host OS folder
Folder Name → shared
Check:
Auto Mount
Make Permanent
Step 3 — Access Shared Folder in VM

Inside VM:

cd /media
ls

You may see:

sf_shared

Access it:

cd /media/sf_shared

If permission denied:

sudo usermod -aG vboxsf cloudera

Reboot:

sudo reboot

Now files copied into host folder appear automatically inside VM.

PART 2 — Save Dataset File

Inside shared folder:

nano system_logs.txt

Paste your dataset.

Save file.

PART 3 — Copy Dataset to Hadoop Project Folder
mkdir ~/logproject
cp /media/sf_shared/system_logs.txt ~/logproject/
cd ~/logproject
PART 4 — Upload Dataset to HDFS

Create HDFS directory:

hdfs dfs -mkdir /logdata

Upload file:

hdfs dfs -put system_logs.txt /logdata

Verify:

hdfs dfs -ls /logdata
PART 5 — Create Correct MapReduce Program

Your dataset uses:

Field 1 = MAC Address
Field 6 = Login Time
Field 8 = Logout Time

We calculate:

Duration = Logout Time - Login Time
Create Java File
nano MaxLoginDuration.java

Paste FULL code below.

FULL WORKING CODE
import java.io.IOException;
import java.text.SimpleDateFormat;
import java.util.Date;

import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.Mapper;
import org.apache.hadoop.mapreduce.Reducer;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;

public class MaxLoginDuration {

    public static class LoginMapper
            extends Mapper<Object, Text, Text, IntWritable> {

        private Text user = new Text();
        private IntWritable durationWritable = new IntWritable();

        public void map(Object key, Text value, Context context)
                throws IOException, InterruptedException {

            try {

                String line = value.toString();

                // Split using tab
                String[] fields = line.split("\\t");

                if(fields.length >= 8) {

                    String mac = fields[0];

                    String loginTimeStr = fields[5];
                    String logoutTimeStr = fields[7];

                    SimpleDateFormat sdf =
                            new SimpleDateFormat("dd-MM-yyyy HH:mm");

                    Date loginTime = sdf.parse(loginTimeStr);
                    Date logoutTime = sdf.parse(logoutTimeStr);

                    long diff =
                            logoutTime.getTime() - loginTime.getTime();

                    int minutes =
                            (int)(diff / (1000 * 60));

                    user.set(mac);
                    durationWritable.set(minutes);

                    context.write(user, durationWritable);
                }

            } catch(Exception e) {
                // Ignore bad records
            }
        }
    }

    public static class LoginReducer
            extends Reducer<Text, IntWritable,
                            Text, IntWritable> {

        public void reduce(Text key,
                           Iterable<IntWritable> values,
                           Context context)
                throws IOException, InterruptedException {

            int total = 0;

            for(IntWritable val : values) {
                total += val.get();
            }

            context.write(key, new IntWritable(total));
        }
    }

    public static void main(String[] args)
            throws Exception {

        Configuration conf = new Configuration();

        Job job =
                Job.getInstance(conf,
                        "Maximum Login Duration");

        job.setJarByClass(MaxLoginDuration.class);

        job.setMapperClass(LoginMapper.class);
        job.setReducerClass(LoginReducer.class);

        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(IntWritable.class);

        FileInputFormat.addInputPath(job,
                new Path(args[0]));

        FileOutputFormat.setOutputPath(job,
                new Path(args[1]));

        System.exit(job.waitForCompletion(true)
                ? 0 : 1);
    }
}

Save file.

PART 6 — Compile Program
export HADOOP_CLASSPATH=$(hadoop classpath)

Compile:

javac -classpath `hadoop classpath` -d . MaxLoginDuration.java
PART 7 — Create JAR
jar -cvf maxduration.jar *.class
PART 8 — Run Hadoop Job
hadoop jar maxduration.jar MaxLoginDuration /logdata /outputdata
PART 9 — View Output
hdfs dfs -cat /outputdata/part-r-00000

Expected type of output:

00-01-6C-D0-9F-25    770

Meaning:

Total login duration = 770 minutes
PART 10 — Copy Output Back to Host OS

Create local output folder:

mkdir result

Copy from HDFS:

hdfs dfs -get /outputdata result

Move to shared folder:

cp -r result /media/sf_shared/

Now output appears directly in your host OS folder.

PART 11 — Important Hadoop Commands
Remove old output directory

Hadoop will fail if output exists.

hdfs dfs -rm -r /outputdata
Check HDFS files
hdfs dfs -ls /
Read HDFS file
hdfs dfs -cat /logdata/system_logs.txt
