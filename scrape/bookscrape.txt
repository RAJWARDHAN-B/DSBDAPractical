Important note first:

books.toscrape.com is a demo website designed for scraping practice.
It does not actually contain customer reviews/comments, usernames, or review tags.
It mainly contains:
Book title
Price
Stock availability
Star rating
Product description
Category

So if you specifically want:

real-time comments
customer names
review tags

you’ll need a different website/API.

Still, I’ll show you:

How to scrape everything available from Books to Scrape
How to structure it like a real review scraper
How to extend it later to Amazon/Goodreads/etc.

6. Extract Book Data

Now loop through books.

Replace your code with:

import requests
from bs4 import BeautifulSoup
import pandas as pd

url = "https://books.toscrape.com/catalogue/category/books_1/index.html"

response = requests.get(url)

soup = BeautifulSoup(response.text, "lxml")

books = soup.find_all("article", class_="product_pod")

data = []

for book in books:

    title = book.h3.a["title"]

    price = book.find("p", class_="price_color").text

    availability = book.find("p", class_="instock availability").text.strip()

    rating = book.find("p")["class"][1]

    data.append({
        "title": title,
        "price": price,
        "availability": availability,
        "rating": rating
    })

df = pd.DataFrame(data)

print(df.head())

8. Scrape Product Description

Each book has its own page.

You need to:

Open each book link
Visit detail page
Extract description

Update loop:

base_url = "https://books.toscrape.com/catalogue/"

for book in books:

    title = book.h3.a["title"]

    relative_link = book.h3.a["href"]

    product_url = base_url + relative_link

    product_response = requests.get(product_url)

    product_soup = BeautifulSoup(product_response.text, "lxml")

    description = product_soup.find(
        "meta",
        attrs={"name": "description"}
    )["content"].strip()

    print(title)
    print(description)

rating_map = {

Use:

rating_text = book.find("p")["class"][1]

rating = rating_map[rating_text]
10. Add Pagination Support

Books span multiple pages.

Example:

page-1.html
page-2.html

Loop through pages:

all_data = []

for page in range(1, 6):

    url = f"https://books.toscrape.com/catalogue/page-{page}.html"

    response = requests.get(url)

    soup = BeautifulSoup(response.text, "lxml")

    books = soup.find_all("article", class_="product_pod")

    for book in books:

        title = book.h3.a["title"]

        rating = book.find("p")["class"][1]

        all_data.append({
            "title": title,
            "rating": rating
        })

print(all_data)
11. Add Real-Time Scraping Behavior

For “real-time” collection:

run scraper periodically
compare new results
store updates

Example using scheduler:

Install:

pip install schedule

Code:

import schedule
import time

def scrape():
    print("Scraping latest books...")

schedule.every(10).minutes.do(scrape)

while True:
    schedule.run_pending()
    time.sleep(1)
12. Add Error Handling

Always use:

try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()
except requests.exceptions.RequestException as e:
    print(f"Request failed: {e}")
13. Add User-Agent Headers

headers = {

response = requests.get(url, headers=headers)
